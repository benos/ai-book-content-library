# Context Registry

Tracks entities and concepts that have been introduced to readers in published book content. Maintained alongside source entry creation.

**Before writing a context note on a new source entry:** check this registry. If the entity or concept is already listed, omit the context note — it is already known. If it is not listed, write the context note and add an entry here after publishing.

**When to update:** after each book generation run, add any newly introduced entities/concepts from the context notes that were deployed.
